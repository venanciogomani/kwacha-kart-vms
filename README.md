# Getting Started

Kwacha kart is a Zambian-targeted eCommerce MultiVendor platform. Vendors can sign up to sale on the platform using the resources we accumulate such as payment methods and delivery, and customers can access the site free of charge.

This is the Vendor Management Service or `VMS` where the storefront is managed. In this dashboard, one can manage stores, vendors, users, products, categories, tags, brands, promotions, locations, payment methods, delivery methods, roles, permissions, plans, site settings, and pages.

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 15.2.6.

## SET UP

Run the following commands to install the application on your local machine:

### If Angular cli is not already installed on your dev server, run `npm install -g @angular/cli`

### `npm i` to install all packages

## Development server

Prior to running the app, ensure that the following micrservices are running:
### `kwacha kart api` running on port 2200
### `kwacha auth` running on port 5000
### A database instance is running on port 8080

Run `ng serve` for a dev server. Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.
